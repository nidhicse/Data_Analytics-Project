The project focusses on identifying disparities in access to and quality of education across different regions, countries, and demographic groups. Data is collected from various sources, including Kaggle and the Human Development Reports, to explore factors contributing to educational inequality such as socio-economic status, gender, ethnicity, and geographic location. The project involves extensive data cleaning, exploratory data analysis (EDA), and predictive modeling to uncover patterns and trends in educational outcomes.
I have applied Python for data analysis, using Pandas for data cleaning, Seaborn for visualizing patterns, and Scikit-learn to build predictive models, such as linear regression, to assess the impact of educational inequality on Human Development Index (HDI) rankings.
